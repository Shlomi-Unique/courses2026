נקודת התחלה: "נובה - קובץ עבודה למפגש 5.xlsx"
  - המודל ממפגש 3, עם 6330 (הוצאות משפטיות) ב-tblAccount.
  - הגיליון "תאריכים" עם הטבלה DimDate: התוצאה של מפגש 4, בלי צורך באינטרנט.
    מי שבנתה את DimDate ב-Power Query במפגש 4 ממשיכה עם שלה.

נתונים: יומן מ-1/1/2025 עד 31/8/2026. תקציב לכל 2025 ו-2026.


-----------------------------------------------------------
שלב 0: המודל (אם עוד לא בניתן במפגש 4)
-----------------------------------------------------------
1. מוסיפים את כל הטבלאות למודל, כולל DimDate.
2. Power Pivot > עיצוב > סמן כטבלת תאריכים, לפי DimDate[תאריך].
3. קשרים:
     tblGL[תאריך אסמכתא]   ->  DimDate[תאריך]
     tblBudget[חודש]        ->  DimDate[תאריך]
     tblGL[כרטיס חשבון]     ->  tblAccount[כרטיס חשבון]
     tblBudget[כרטיס חשבון] ->  tblAccount[כרטיס חשבון]
     tblGL[מחלקה]           ->  tblDepartment[מחלקה]
     tblBudget[מחלקה]       ->  tblDepartment[מחלקה]
     tblAccount[סעיף דוח]   ->  tblReportLine[סעיף דוח]
4. tblMonth לא בשימוש. מסתירים או מוחקים.
5. מיון: DimDate[שם חודש] לפי DimDate[מס חודש]. tblReportLine[סעיף דוח] לפי [סדר הצגה].


-----------------------------------------------------------
שלב 1: מדדי בסיס (כולם בטבלת tblGL, או בטבלה ריקה בשם "_מדדים")
-----------------------------------------------------------
ביצוע := SUM ( tblGL[ביצוע] )

תקציב := SUM ( tblBudget[תקציב] )

סטייה := [ביצוע] - [תקציב]

סטייה % := DIVIDE ( [סטייה], [תקציב] )

בדיקה, 2025: ביצוע 4,003,140, תקציב 4,035,000.
  הכנסות ממכירות: ביצוע 2,240,000, תקציב 2,329,500, סטייה -89,500 (-3.8%)
  הנהלה וכלליות:  ביצוע 107,800,  תקציב 84,000,   סטייה 23,800 (28.3%)

שימו לב: "ביצוע" חיובי גם בהכנסות וגם בהוצאות. ה-4,003,140 הוא לא רווח.


-----------------------------------------------------------
שלב 2: רווח, וסטייה "לטובה" או "לרעה"
-----------------------------------------------------------
רווח :=
SUMX ( tblGL, tblGL[ביצוע] * RELATED ( tblReportLine[סימן] ) )

תקציב רווח :=
SUMX ( tblBudget, tblBudget[תקציב] * RELATED ( tblReportLine[סימן] ) )

סטייה לטובה := [רווח] - [תקציב רווח]

הסבר:
  - "סימן" ב-tblReportLine: 1 להכנסות, -1 להוצאות.
  - RELATED עובר בשרשרת: tblGL > tblAccount > tblReportLine.
  - "סטייה לטובה" חיובית = טוב לרווח. בהכנסות: מעל התקציב. בהוצאות: מתחת לתקציב.
    כך אין צורך לזכור בכל שורה אם פלוס זה טוב או רע.

בדיקה, 2025: רווח נקי 559,260, תקציב רווח 705,600, סטייה לטובה -146,340.
  עלות המכר: סטייה 19,500, סטייה לטובה -19,500
  שכר ונלוות: סטייה -200, סטייה לטובה 200


-----------------------------------------------------------
שלב 3: CALCULATE
-----------------------------------------------------------
הכנסות := CALCULATE ( [ביצוע], tblReportLine[קבוצת דוח] = "הכנסות" )

תקציב הכנסות := CALCULATE ( [תקציב], tblReportLine[קבוצת דוח] = "הכנסות" )

אחוז מהכנסות := DIVIDE ( [ביצוע], CALCULATE ( [הכנסות], ALL ( tblReportLine ) ) )

בדיקה, 2025: הכנסות 2,281,200. עלות המכר = 28.5% מההכנסות.


-----------------------------------------------------------
שלב 4: מתחילת השנה (YTD)
-----------------------------------------------------------
הכנסות מתחילת השנה := TOTALYTD ( [הכנסות], DimDate[תאריך] )

תקציב הכנסות מתחילת השנה := TOTALYTD ( [תקציב הכנסות], DimDate[תאריך] )

רווח מתחילת השנה := TOTALYTD ( [רווח], DimDate[תאריך] )

בדיקה, הכנסות 2026 מצטבר:
  חודש     הכנסות מתחילת השנה   תקציב מתחילת השנה
  ינואר    161,000              198,500
  מרץ      497,500              595,400
  יוני     1,038,400            1,207,200
  אוגוסט   1,411,000            1,634,900

הערה: TOTALYTD עובד רק אם DimDate מסומנת כטבלת תאריכים, ואין בה חורים.


-----------------------------------------------------------
שלב 5: שנה קודמת, והמלכודת
-----------------------------------------------------------
הכנסות שנה קודמת := CALCULATE ( [הכנסות], SAMEPERIODLASTYEAR ( DimDate[תאריך] ) )

ברמת חודש זה עובד: אוגוסט 2026 מול אוגוסט 2025 = 199,100 מול 213,000.
ברמת שנה זו מלכודת: 2026 מול 2025 = 1,411,000 מול 2,281,200 (ירידה של 38%)
  למה? ב-2026 יש נתונים רק עד אוגוסט, אבל SAMEPERIODLASTYEAR מחזיר את כל 2025.

התיקון: משווים רק עד התאריך האחרון שיש בו נתונים.

תאריך אחרון := CALCULATE ( MAX ( tblGL[תאריך אסמכתא] ), ALL ( tblGL ) )

הכנסות שנה קודמת (תקופה מקבילה) :=
VAR LastDate = [תאריך אחרון]
RETURN
    CALCULATE (
        [הכנסות],
        SAMEPERIODLASTYEAR (
            FILTER ( VALUES ( DimDate[תאריך] ), DimDate[תאריך] <= LastDate )
        )
    )

שינוי משנה קודמת % :=
DIVIDE (
    [הכנסות] - [הכנסות שנה קודמת (תקופה מקבילה)],
    [הכנסות שנה קודמת (תקופה מקבילה)]
)

בדיקה: 2026 = 1,411,000 מול 1,548,400, שינוי -8.9%.

  ערכים: ביצוע, תקציב, סטייה לטובה, סטייה %
  עיצוב מותנה על "סטייה לטובה": סרגלי נתונים, או חצים (ירוק מעל 0, אדום מתחת)

טבלת ציר 2, הכנסות מצטבר:

  ערכים: הכנסות מתחילת השנה, תקציב הכנסות מתחילת השנה
  תרשים ציר: קו. הפער בין הקווים הוא הסיפור של 2026.

טבלת ציר 3, מספרי מפתח (כרטיסים):
  ערכים: הכנסות, רווח, סטייה לטובה, שינוי משנה קודמת %
  פריסה: בשורה אחת, בלי כותרות שורה.

כלי פריסה: DimDate[שנה], tblDepartment[שם מחלקה].
  קליק ימני > חיבורי דוח > מחברים את שני כלי הפריסה לכל טבלאות הציר.

שלב 7: התרגיל בכיתה
-----------------------------------------------------------
רווח שנה קודמת (תקופה מקבילה) :=
VAR LastDate = [תאריך אחרון]
RETURN
    CALCULATE (
        [רווח],
        SAMEPERIODLASTYEAR (
            FILTER ( VALUES ( DimDate[תאריך] ), DimDate[תאריך] <= LastDate )
        )
    )

בדיקה, 2026: רווח 254,820, רווח שנה קודמת (תקופה מקבילה) 396,570.
סטייה לטובה לפי מחלקה, 2026:

-----------------------------------------------------------
שגיאות צפויות
-----------------------------------------------------------
- TOTALYTD מחזיר את אותו מספר כמו החודש: DimDate לא מסומנת כטבלת תאריכים,
  או שבטבלת הציר החודש נלקח מ-tblMonth ולא מ-DimDate.
- "לא ניתן לקבוע ערך בודד": כתבו tblGL[ביצוע] בתוך מדד בלי SUM.
- RELATED לא מוצא את הטבלה: חסר קשר בשרשרת, בדרך כלל tblAccount > tblReportLine.
- שורת "(ריק)": כרטיס ביומן שלא קיים ב-tblAccount. בקובץ למפגש 5 כבר הוספנו את 6330.
- סטייה % מוצגת כ-0.04: עיצוב המדד כאחוז, בחלון המדד ולא בטבלת הציר.


-----------------------------------------------------------
תרגיל הבית: פתרון
-----------------------------------------------------------
צפי רווח לסוף שנה :=
VAR LastDate = [תאריך אחרון]
VAR Y = MAX ( DimDate[שנה] )
RETURN
    CALCULATE ( [רווח], FILTER ( ALL ( DimDate ), DimDate[שנה] = Y && DimDate[תאריך] <= LastDate ) )
  + CALCULATE ( [תקציב רווח], FILTER ( ALL ( DimDate ), DimDate[שנה] = Y && DimDate[תאריך] > LastDate ) )

בדיקה, 2026: 254,820 + 252,300 = 507,120 (תקציב הרווח לכל השנה: 682,100).
לשים לב: המדד נכון ברמת שנה. ברמת חודש הוא מחזיר את הצפי של כל השנה בכל חודש (בגלל ALL).
ב-2025 אין תאריכים אחרי התאריך האחרון, ולכן הצפי = הרווח בפועל, 559,260.

ימי עבודה := CALCULATE ( COUNTROWS ( DimDate ), DimDate[יום עבודה] = 1 )
הכנסות ליום עבודה := DIVIDE ( [הכנסות], [ימי עבודה] )

בדיקה, 2026: אפריל 174,900 ב-19 ימי עבודה = 9,205 ליום, הגבוה בשנה.
אוגוסט 199,100 ב-22 ימים = 9,050. מרץ 171,500 ב-23 ימים = 7,457, הנמוך בשנה.
