פרומפטים למפגש 4: טבלת תאריכים וחגים

עובדים בכל כלי · תמיד בודקים את התוצאה מול תאריך שידוע לכן

1. פונקציה לתאריך הפסחא

תכתוב לי פונקציה ב-Power Query (שפת M) בשם fnEaster,
שמקבלת שנה (מספר) ומחזירה את תאריך חג הפסחא הנוצרי (Easter) בלוח הגרגוריאני.
בלי חיבור לאינטרנט. תוסיף הערה קצרה בעברית ליד כל שלב.

בדיקה: 2025 = 20/04/2025, 2026 = 05/04/2026.

2. טבלת תאריכים

תכתוב לי שאילתת Power Query שבונה טבלת תאריכים מ-1/1/2025 עד 31/12/2027,
עם העמודות: תאריך, שנה, רבעון, מספר חודש, שם חודש בעברית,
יום בשבוע (ראשון = 1), שם יום בעברית, וסוף שבוע (שישי ושבת = 1).

3. תרגום שמות חגים

אלה שמות חגים מוסלמיים כפי שהם חוזרים מ-API באנגלית:

אחר כך תכתוב לי שלב M שממזג את הטבלה הזו לשאילתה שלי.

4. שנת כספים שלא מתחילה בינואר

שנת הכספים בחברה שלי מתחילה ב-1 באפריל.

ו"חודש בשנת הכספים" (אפריל = 1). זה הקוד שלי עד עכשיו:
