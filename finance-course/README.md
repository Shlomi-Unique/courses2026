# finance-course

עותק של הקבצים החיים מהתיקייה `public_html/finance-course` ב-cPanel (uniquetech.co.il/finance-course/).

| קובץ | מה הוא |
|---|---|
| `index.html` | דף הנחיתה של הקורס "איש הכספים החדש" (כולל חלון קופץ לסילבוס ודרישת ידע מוקדם) |
| `mechkar.html` | דף המחקר "אתה לא לבד" עם טופס ליד להדרכות פנים-ארגוניות |
| `lead.php` | שולח כל טופס מדף המחקר במייל (גיבוי לוואטסאפ) |
| `thank-you.html` | דף התודה אחרי תשלום ב-SUMIT, מדווח רכישה לפיקסל של מטא |

התיקייה `assets` (וידאו, באנרים, סילבוס PDF) לא נשמרה כאן. היא נמצאת רק ב-cPanel.

כשמשנים קובץ באתר, לעדכן גם כאן.
