קובץ התחלה: "נובה - הפצת דוחות למנהלים.xlsx"
  דוח מחלקה   הדוח שנשלח. בוחרים מחלקה בתא B2 (השם DeptCell), והכל מתעדכן בנוסחאות.
              סכומים למחלקה בלבד, בלי שכר של עובד בודד.
  מנהלים      tblManagers: מחלקה | שם מנהל | מייל | לשלוח (TRUE/FALSE)
              הכתובות בדויות (nova.example). לפני הרצה אמיתית מחליפים לכתובת שלכן.
  הגדרות      שנה, עד חודש, תיקייה, לשלוח מיד, נושא וגוף המייל. כולם שמות מוגדרים.
  תלושים, תקן ותקציב, עובדים, מחלקות   הנתונים ממפגש 7.

קבצי הפתרון:
  modDeptReports.bas              לייבוא ישיר: עורך VBA > File > Import File
  modDeptReports.txt              אותו קוד, לקריאה או להעתקה (מתחיל מ-Option Explicit)
  modDeptReports_עם_באגים.txt     לפינת ה-AI


-----------------------------------------------------------
שלב 0: הכנה
-----------------------------------------------------------
1. שומרים בשם > חוברת עבודה של Excel עם מאקרו (*.xlsm).
2. מפתחים > Visual Basic (או Alt+F11). Insert > Module.
3. אם הכרטיסייה "מפתחים" לא מופיעה: קובץ > אפשרויות > התאמה אישית של רצועת הכלים > מפתחים.
4. מאקרו לא רץ? קובץ > אפשרויות > מרכז האמון > הגדרות מאקרו. עדיף: תיקייה מהימנה, ולא "אפשר את כל המאקרו".
5. קבצים שהורדו מהאינטרנט: קליק ימני על הקובץ > מאפיינים > "בטל חסימה".


-----------------------------------------------------------
שלב 1: מקליטים, ואז מבינים (הדגמה 1)
-----------------------------------------------------------
מפתחים > הקלט מאקרו. בוחרים מחלקה 20 ב-B2, קובץ > ייצא > PDF. עוצרים הקלטה.
פותחים את הקוד: רואים Range("B2"), נתיב קבוע, ושם קובץ קבוע.
המסר: ההקלטה נותנת את הפקודה הנכונה (ExportAsFixedFormat). את הלולאה ואת המייל כותבים בעצמנו, או עם AI.


-----------------------------------------------------------
שלב 2: הקוד המלא (modDeptReports)
-----------------------------------------------------------
שלושה צעדים בתוך לולאה על tblManagers:
  1. Range("DeptCell") = מחלקה, Application.Calculate
  2. ExportAsFixedFormat ל-PDF: Report_<מחלקה>_<שנה>-<חודש>.pdf
  3. Outlook: CreateItem(0), To, Subject, HTMLBody עם dir="rtl", Attachments.Add, Display או Send

נקודות חשובות:
  - SendNow = FALSE כברירת מחדל. ההרצה הראשונה פותחת 4 טיוטות, ולא שולחת כלום.
  - הקוד לא מכיל עברית. שמות גיליונות, נושא וגוף המייל נמצאים בקובץ. כך הקוד לא נשבר
    כשמשנים שם של גיליון, ואין בעיות קידוד.
  - CreateObject("Outlook.Application") עובד בלי להוסיף Reference. (Late binding)
  - בסוף מחזירים את הדוח למחלקה שהייתה בו.

-----------------------------------------------------------
שלב 3: כפתור
-----------------------------------------------------------
הוספה > צורות > מלבן מעוגל בגיליון ההגדרות. קליק ימני > הקצה מאקרו > SendDeptReports.


-----------------------------------------------------------
פינת ה-AI: שלושת הבאגים בגרסה "המהירה"
-----------------------------------------------------------
1. folder = ThisWorkbook.Path בלי "\" בסוף.
   הקובץ נשמר כ-...\תיקייהReport_10.pdf, תיקייה אחת למעלה ובשם אחר.
2. .To = Cells(1, 2) הוא שם המנהל, לא המייל (עמודה 3). Outlook לא מזהה נמען.
3. Attachments.Add לפני ש-ExportAsFixedFormat יצר את הקובץ.
   בהרצה ראשונה: שגיאה "לא ניתן למצוא את הקובץ". בהרצה שנייה: מצורף הדוח הישן. זה הבאג המסוכן.
בונוס, דברים שעובדים אבל שבירים:
  - הטבלה נמצאת לפי "הגיליון הרביעי אחרי הדוח". הזזת גיליון שוברת את הקוד. (בפתרון: GetTable לפי שם)
  - אין Application.Calculate. בקובץ עם חישוב ידני כל הדוחות יצאו זהים.
  - אין בדיקה של העמודה "לשלוח".
  - .Body במקום .HTMLBody: עברית בלי כיוון מימין לשמאל.


-----------------------------------------------------------
תרגיל הבית: פתרון
-----------------------------------------------------------
חלק א, לוג: גיליון "לוג" עם טבלה tblLog (זמן | מחלקה | מייל | קובץ). אחרי כל מייל:
    Dim lo As ListObject, nr As ListRow
    Set lo = GetTable("tblLog")
    Set nr = lo.ListRows.Add
    nr.Range.Cells(1, 1).Value = Now
    nr.Range.Cells(1, 2).Value = deptNo
    nr.Range.Cells(1, 3).Value = row.Range.Cells(1, 3).Value
    nr.Range.Cells(1, 4).Value = pdfPath
  בדיקה: 4 שורות בכל הרצה.

חלק ב, העתק למנהלת הכספים: שם מוגדר CfoMail בגיליון ההגדרות, ובתוך With olMail:
    If Trim$(CStr(Range("CfoMail").Value)) <> "" Then .CC = Range("CfoMail").Value

חלק ג, טיפול בשגיאות (מה שה-AI צפוי להציע):
    On Error GoTo NextDept   ...   NextDept: אם יש שגיאה, כותבים ללוג ועוברים למחלקה הבאה.
  החשוב: לא On Error Resume Next על כל הקוד. כך שגיאות נעלמות בשקט, כמו IFERROR במפגש 6.

בונוס, התראה: שולחים רק אם הסטייה לטובה שלילית (חריגה):
    If wsReport.Range("D22").Value < 0 Then ... (או שם מוגדר YtdVariance על D22)
  בדיקה: רק הנהלה (-2,285) מקבלת מייל.
