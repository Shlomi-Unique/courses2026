שלב 3: יחסים פיננסיים
-----------------------------------------------------------
יחס שוטף = נכסים שוטפים / התחייבויות שוטפות          3.01  ->  3.52
יחס מהיר = (נכסים שוטפים - מלאי) / התחייבויות שוטפות  2.21  ->  2.66
חוב להון = (חלויות + הלוואה) / הון עצמי              0.29  ->  0.20
הון חוזר = נכסים שוטפים - התחייבויות שוטפות          744,000  ->  1,000,420
ימי לקוחות (DSO) = לקוחות / הכנסות * ימים
   2025: 386,000 / 2,281,200 * 365 = 61.8
   2026: 452,000 / 1,411,000 * 243 = 77.8    (243 ימים מ-1/1 עד 31/8)
ימי מלאי (DIO) = מלאי / עלות המכר * ימים
   2025: 298,000 / 651,000 * 365 = 167.1
   2026: 341,000 / 458,000 * 243 = 180.9

הסיפור: היחסים נראים מצוין. אבל ההכנסות ירדו, והלקוחות והמלאי עלו.
לקוחות משלמים 16 ימים לאט יותר, והמלאי שוכב 14 ימים יותר. הכסף "תקוע" בהון החוזר.
