2. כתיבת המאקרו מאפס

תכתוב לי מאקרו VBA לאקסל שעובר על טבלה בשם tblManagers
(עמודות: מחלקה, שם מנהל, מייל, לשלוח).
לכל שורה שבה "לשלוח" הוא TRUE:
1. כותב את מספר המחלקה בתא שהשם המוגדר שלו DeptCell, ומחשב מחדש.
2. שומר את הגיליון של DeptCell כ-PDF בתיקייה של הקובץ.
3. פותח מייל ב-Outlook עם ה-PDF מצורף, לנמען מהעמודה "מייל".
   נושא וגוף המייל מהשמות המוגדרים MailSubject ו-MailBody. גוף המייל מימין לשמאל.
4. שולח רק אם השם המוגדר SendNow הוא TRUE. אחרת רק מציג את הטיוטה.
בלי עברית בתוך הקוד, ובלי Reference ל-Outlook (late binding).

3. מציאת באגים

המאקרו הזה אמור לשלוח לכל מנהל מחלקה את הדוח שלו כ-PDF.
הוא "עובד כמעט". תמצא את כל הבאגים, תסביר לכל אחד מה יקרה בפועל
(גם בהרצה הראשונה וגם בהרצה השנייה), ותכתוב גרסה מתוקנת.
[מדביקים את modDeptReports_עם_באגים]

בלי On Error Resume Next על כל הקוד. תסביר למה.
